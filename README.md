# Diabetes Prediction: Machine Learning Model Comparison

A comparative analysis of conventional machine learning and deep neural network classifiers using the Pima Indians Diabetes dataset.

## Project questions

- How do different classifiers compare under a consistent evaluation procedure?
- What effect does preprocessing or feature engineering have?
- Which errors are most important when interpreting screening-oriented predictions?

## Tools and methods

- Python
- machine learning
- deep neural networks
- feature engineering
- preprocessing
